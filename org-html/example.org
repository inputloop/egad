about: headlines, =TODO= keywords, priorities, tags, timestamps, tables, source

to a page a person can read, so it comes before any component library.

def contrast(a, b):
    """WCAG 2.1 relative-luminance ratio."""
    la, lb = sorted((lum(a), lum(b)), reverse=True)
    return (la + 0.05) / (lb + 0.05)
